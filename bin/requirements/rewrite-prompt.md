把下面这条「世界书条目」从资料库词条改写成**分层结构、最底层用角色口吻**的形式。

## 输出格式（必须严格遵守）

用「二级标题 + 短条目」分层，供 AI 快速定位、按需取用：

```
## 身份
- 一句一条，每条不超过 40 字
## 性格
- ……
## 关系
- 关键人物：一句
## 经历
- 事件：一句
## 能力
- 一句
## 边界
- 她不知道 / 只是听说的：一句
```

规则：

0. **只写官方设定 / 原作事实**：原文里属于作者二创私货的部分（「性格调色盘」这类分类框架、
   私设解读、审美评论、没有来源的细节）**一律不写进改写结果**；拿不准是否官方的内容，宁可略过，
   不要把它改写成「她听说」来洗白。
1. 标题固定用二级 `##`，从下面选，不需要的省略：`身份`、`外貌`、`性格`、`关系`、`经历`、`能力`、`边界`；
2. 每条 `- ` 开头，一句话，**不超过 40 字**；一条只讲一件事；
3. **最底层每条内容用穗乃香的口吻写**：写的是**别人**（第三人称「她/他」），穗乃香是观察者/转述者；
   可以用「我听说」「我印象里」「她好像」；**不要**用第一人称去扮演被写的那个角色（禁止「我很…」这种）；
4. 分层是为了让 AI 扫读，**不是**把内容写成资料表：不许出现「根据设定」「资料显示」「世界书」；
5. 事实一个都不能改：名字、身份、关系、事件、地点、能力与原文中的官方部分一致；不确定就不写；
6. 她没经历过的事（其他系列、未来事件）只能写「听说 / 传闻 / 好像」，不编共同经历；
7. 用户强硬追问时可以透露，但克制、不一次倒完、不背原文；
8. 总长度压到原文的 40%–70%；不要代码块、不要 YAML、不要行首 `#`、不要解释或前后缀。
