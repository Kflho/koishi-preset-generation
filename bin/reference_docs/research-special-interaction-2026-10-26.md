# 特殊互动素材卡（2026-10-26，首版）

**用途**：给「对话例子-特殊互动」提供可溯源素材，避免模型自由发挥、背履历、把未来作品当已知。
**边界**：只写「她可能知道什么」和「怎么接」；不改人设核心，不把元信息写进世界书。

## 0. 结论先行

- 破墙互动优先用「同声优」：素材最硬、最好笑、最容易验证。
- 时间线是硬边界：2004 年之后的作品只能「没看过 / 好像听说过」，不能当已知。
- 每条示例只选一个点，不背履历；趣味来自「她把元信息翻译成自己的生活语言」。
- 分层（用户文档 2.1.2.1）：**素材/知识进世界书**（`特殊互动素材` 条目，事实卡，≤600 字符）；
  **风格/参考例子进预设**（三个对话示例子节）。

## 10. 复核与待核

**已核**

- 声优署名：东映公式页（一手）；
- 旧名 / 改名 / 生日 / 出身：ja wiki；
- 中文译名 / 旧艺名：zh wiki；
- 制作名单：ja wiki staff；
- 角色设定与剧情：朝日公式页 + ja wiki + `穗乃香_世界书.yml`（内源）。

**待核（不写进对话）**

- 吵架「谁先道歉」：没有找到一手来源，只写「奶奶提醒」；
- 「亮太喜欢假面骑士」这类日常细节：未核，不采用；
- 20 周年的具体年份：按 2004 起算为 2024，对话里不报具体年份。

**不采用**

- 把风格例子写进世界书（世界书只放事实卡，例子留在预设）；
- 把 Love Live 当已知；
- 把 Code Geass 剧情当已知；
- 让角色主动科普「声优 / 公司 / 作者」。

## 11. 落点：世界书两个素材条目

- `特殊互动素材`：声优、同声优代表作、同年代、同题材、同公司、作者、时间边界；≤600 字符；
- `特殊互动素材`：自己声优/同年代/同题材/同公司/作者；≤600 字符；
- `特殊互动素材_声优角色表`：一张表列出所有特殊互动声优 → 角色 → 作品（关键词=全部角色名+声优名+作品名）；≤600 字符；
- 重要角色单独条目（七咲逢×絢辻詞、月島雫…）；其余角色只进表，不单开；
  所有条目开头标 `特殊互动分类：…`。
- 两个条目都在 `bin/requirements/世界书/穗乃香_世界书.yml`，`scanDepth: 1`；
- 风格：预设 `#### 特殊互动对话示例`，16 条（含履历复读挡板 + 3 条同班/同系列梗）；
- 角色互动：预设 `#### 角色互动对话示例`，8 条；事实在 `穗乃香_世界书.yml` 自身条目。
